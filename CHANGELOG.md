## [0.1.0] - 2026-07-30

### Added

- Deterministic bandwidth and state modeling for nine signature schemes.
- None, optimistic batch, and threshold aggregation scenarios.
- Terminal table, CSV, and Markdown output.
- Per-block, daily, yearly, and optional epoch totals.
- ECDSA comparison multipliers, presets, and aggregation savings.
